# NYVERRA: Echo Frontier — Alpha 0.58
## Серверное строительство, рейды и ремонт

Дата: 2026-11-08. Репозиторий: `Zeihos/NYVERRA-Echo-Frontier`, закрытый `main`.

### Реализовано в C++ (не результат игрового теста)

| Механика | Правило |
| --- | --- |
| Прочность фундамента | 600 HP, репликация с сервера |
| Прочность стены | 360 HP, репликация с сервера |
| Рейд в ближнем бою | 35 урона за попадание; существующий серверный интервал атак 0,75 с |
| Удаление объекта | При 0 HP сервер уничтожает Actor, уничтожение реплицируется клиентам |
| Собственность | `BuilderPlayerState` назначается при размещении, передаётся другим игрокам |
| Ремонт | Только текущий владелец, **R**, требует 1 дерево + 1 камень, восстанавливает максимум 75 HP |
| Задержка ремонта | 12 с после последнего попадания; нельзя мгновенно чиниться во время рейда |
| Контроль клиента | RPC ремонта не принимает цель, количество ресурсов и количество HP |
| UI | Название и HP постройки под прицелом, зелёная / жёлтая / красная полоска |
| Защита от прострела | Сервер наносит урон только первому Actor в луче `ECC_Visibility` |

Никаких дропов ресурсов при разрушении построек пока нет — это предотвращает простое размножение материалов через собственные постройки. Постройки без действующего `PlayerState` не создаются. Сохранение владельца после выхода из игры пока не реализовано; после переподключения (в новом сеансе) владение потребуется перенести на постоянную учётную запись.

### Как проверить на Windows

В локальном Git-клоне:

```bat
git pull origin main
TEST_ALPHA_058_WINDOWS.bat
```

При установленном Unreal Engine 5.8 скрипт выполнит Python-проверки и попытается собрать `NYVERRAEditor`. Пример нестандартной установки:

```bat
TEST_ALPHA_058_WINDOWS.bat "D:\Epic Games\UE_5.8"
```

### Обязательные тесты в PIE

1. Запустить сохранённую карту **с двумя игроками**, Net Mode = Listen Server.
2. Собрать дерево и камни, создать фундамент клавишей **1** и стену клавишей **2**. Проверить списание ресурсов и начальные 600/360 HP на обоих клиентах.
3. Вторым игроком атаковать стену через ЛКМ. За один подтверждённый удар прочность снижается на **35** только у ближайшей постройки.
4. Повторить удар через существующую стену по стоящему за ней игроку. Урон через стену проходить не должен.
5. Убедиться, что чужой игрок **не может чинить** постройку; дерево/камень у него не тратятся.
6. Владельцем попробовать R сразу после удара. До истечения **12 секунд** ремонт должен блокироваться, ресурсы сохраняются.
7. После задержки нажать R: 1 дерево + 1 камень списываются, прочность повышается максимум на 75, но не выше полной.
8. Прицелиться на постройку с обоих клиентов: проверить текущее HP и цвет полосы.
9. Разрушить постройку до 0. Она должна исчезнуть на обоих клиентах. Повторные атаки не создают награды.
10. При открытом инвентаре проверить, что случайное нажатие R/LMB не выполняет действий; клиент без `PlayerState` не должен создавать «бесхозную» постройку.
11. Протестировать одновременный ремонт и атаки, повторные RPC и поведение после смерти владельца.
12. После успешного PIE проверить отдельный клиент и выделенный сервер, затем собрать Windows-пакет.

### Не подтверждено и ещё не реализовано

- Компиляция **именно версии 0.58** в установленном UE5.8; реальный мультиплеерный тест, выделенный сервер и сохранённая .umap в GitHub.
- Глубокие рейды: взрывчатка, дверные замки, права команды, постоянные идентификаторы владельцев, защита от offline-рейдов, автосохранение баз, сезонные вайпы.
- Финальные 3D-модели/анимации, релизная графика и исполняемая сборка Windows.

Не отмечать проект как готовый релиз по результатам статических проверок.

# Участие в разработке NYVERRA

Спасибо за интерес к NYVERRA: Echo Frontier. Проект на стадии Alpha: основная задача — исправлять проблемы и улучшать уже существующие системы без потери работоспособности Unreal Engine 5.8.

## Как предложить изменение

1. Проверьте [текущее состояние](docs/STATUS.md) и [инструкцию разработки](docs/DEVELOPMENT.md).
2. Создайте отдельную ветку от актуального `main` (например, `fix/resource-replication` или `feature/inventory-save`).
3. Изменяйте только относящиеся к задаче файлы. Если правите C++, приложите сценарий проверки в Unreal Engine.
4. Запустите `py -3 -m unittest discover -s Tools -p "test_alpha_*.py" -v`. Если есть UE5.8 — дополнительно `TEST_ALPHA_061_WINDOWS.bat`.
5. Откройте Pull Request с описанием изменений, результата проверок и оставшихся ограничений.

## Правила репозитория

- Основной язык документации и обсуждений — **русский**. Технические имена классов/методов оставляйте на языке кода.
- Не включайте `Binaries/`, `Intermediate/`, `Saved/`, локальные журналы, приватные ключи и идентификаторы игроков.
- Не перезаписывайте авторскую `TestWorld.umap` или существующие материалы скриптом без явной проверки и резервной копии.
- Для сохранений, сетевых RPC и базы данных обязательны проверки прав доступа и отсутствие дублирования предметов.
- Не утверждайте, что что-то «работает в UE», если запуск не проводился. Указывайте, что проверено в Python, что собрано C++ и что испытано в PIE / Standalone / dedicated server.
- Не добавляйте чужие ассеты, слитые игровые исходники, текстуры или музыку без понятных прав использования и происхождения.

## Лицензирование

Репозиторий открыт для просмотра, но опубликованного файла `LICENSE` нет. Это **не означает разрешения на свободное использование** содержимого. Перед созданием большого Pull Request обсудите с владельцем условия вклада и дальнейшего использования его результатов.

## Сообщения об ошибках

Создайте Issue по шаблону «Ошибка». Прикладывайте шаги воспроизведения, версию UE, log (без персональных данных) и скриншоты, если нужны. Информация об уязвимостях — отдельно, по [SECURITY.md](SECURITY.md).

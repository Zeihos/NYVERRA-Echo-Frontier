Windows sequence:
1. Extract the ZIP, install UE 5.8 and Visual Studio C++ toolchain.
2. Run CHECK_ALPHA_034.bat (requires Python 3).
3. Run BUILD_ALPHA_033_WINDOWS.bat or build NYVERRAEditor from Visual Studio.
4. If building succeeds: in Editor, Tools -> Execute Python Script -> Tools/create_test_world.py.
5. Open TestWorld; Tools -> Execute Python Script -> Tools/validate_runtime_map_034.py.
6. Build Paths, press P, then test 2 clients (Play Settings -> Number of Players = 2).
7. If compilation fails, provide the FIRST compiler error and BUILD_ALPHA_033.log.

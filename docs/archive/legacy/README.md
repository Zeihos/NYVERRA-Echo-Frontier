# Исторические материалы ранних версий

Эта папка **не является рабочим каталогом игры**. Сюда перенесены:

- `ALPHA_023.txt` — `ALPHA_053_CHANGES.txt`: заметки и протоколы разработки ранних Alpha.
- `TESTING_017.txt` — `TESTING_022.txt`: старые планы и инструкции тестирования.
- `BUILD_ALPHA_033/036/046/047_WINDOWS.bat`, `CHECK_ALPHA_031/032/034/035.bat`: устаревшие сценарии ранней сборки и проверки.
- `PUSH_TO_GITHUB_PRIVATE*.bat`, `PUSH_NYVERRA_RESUME_MAIN.bat`: старые сценарии первичной загрузки в **Private**-репозиторий.
- `DOWNLOAD_ALL_PARTS_FIRST.txt`, `GITHUB_UPLOAD_INSTRUCTIONS_RU.txt`, `HISTORY_CHECKSUMS_SHA256.txt`: инструкции и контрольные суммы старых архивов.
- `LANDSCAPE_IMPORT_019.txt`: исторические инструкции по карте.

**Важно:** эти файлы сохранены для истории. Старые BAT могут содержать предположения о путях и приватности репозитория, которые больше не верны. **Не запускайте их из этой папки.** Для проверки текущей Alpha используйте [CHECK_PROJECT_WINDOWS.bat](../../../CHECK_PROJECT_WINDOWS.bat) из корня.

Актуальная документация: [главная страница](../../../README.md), [сборка](../../DEVELOPMENT.md), [статус](../../STATUS.md), [история изменений](../../../CHANGELOG.md).

Все исторические тексты и скрипты сохранены в Git без изменения содержимого; при необходимости прежние расположения доступны в истории коммитов.

# Архив материалов NYVERRA

Здесь собраны **исторические** отчёты разработки и инструкции ранних Alpha-версий. Они сохранены для изучения истории проекта, но **не являются актуальными руководствами по сборке и запуску**.

## Структура

- [Архивные заметки Alpha 0.17–0.53](legacy/) — исходные текстовые отчёты, инструкции и проверки старых прототипов.
- [История Alpha 0.20–0.22](ALPHA_020_022_CHANGELOG.txt) — ранний журнал изменений.
- [Текущая история версий](../../CHANGELOG.md) — актуальный журнал.
- [Актуальные инструкции](../DEVELOPMENT.md) — сборка, тесты и Unreal Engine 5.8.
- [Состояние проекта](../STATUS.md) — что реализовано и что ещё не подтверждено.

Исторические сценарии загрузки на GitHub из раннего комплекта перемещены в `legacy/` **только для хранения**. Их нельзя использовать для обновления нынешнего публичного репозитория: старые сценарии предполагают закрытую видимость и могут массово добавить локальные файлы. Для обычной работы используйте стандартные Git-команды из актуальной инструкции.

Файлы перемещены без изменения содержимого, а их прежние версии остаются доступны через историю Git.

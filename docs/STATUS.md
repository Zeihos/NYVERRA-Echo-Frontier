# Текущее состояние NYVERRA

Обновлено: **17 ноября 2026** · Текущая ветка: `main` · Этап: **Alpha 0.61**

Этот файл разделяет *наличие кода* и *проверенную работоспособность*.

| Подсистема | В исходниках | Реальная проверка |
| --- | --- | --- |
| Персонаж, движение, взаимодействия | Есть | Ранее проверены отдельные функции в одиночном PIE; для Alpha 0.61 повторной проверки нет |
| Инвентарь, сбор, крафт, еда и вода | Прототип | Новый код не подтверждён игровыми тестами |
| PvE, рукопашные PvP-атаки | Прототип | Не подтверждены тесты двух игроков |
| Фундаменты, стены, двери и рейды | Прототип | Не подтверждены тесты строительства и авторизации на сервере |
| Сохранения построек A/B | Код Alpha 0.61 | **Не проверены** запись на диск и восстановление после перезапуска |
| Графика: PBR-материалы и HUD | Скрипты и код | Нет подтверждения импорта всех PNG/`.uasset` и шейдеров в UE5.8 |
| Сохранённая тестовая карта `TestWorld.umap` | Генератор есть | Сам проверенный файл карты отсутствует в GitHub |
| Выделенный сервер / Windows-пакет | Частичные скрипты и настройки | Не подтверждены |
| Аккаунты, кланы, рейды полного цикла, вайпы | Не закончены | Не проверялись |

## Что обязательно сделать перед следующим крупным релизом

1. Установить Unreal Engine **5.8**, C++-компилятор Visual Studio и Python 3 на Windows.
2. Выполнить [локальную проверку](DEVELOPMENT.md) и устранить любые ошибки компиляции.
3. Сохранить проверенную карту `Content/Maps/TestWorld.umap` вместе с зависимыми ассетами в GitHub.
4. Проверить мир с двумя игроками: взаимодействия, ресурсы, бой, строительство, двери, рейды.
5. Проверить **Standalone / dedicated-server** сохранения построек по [Alpha 0.61 QA](../ALPHA_061_QA.md); PIE специально не пишет постоянные данные.
6. Проверить загрузку материалов и производительность в Unreal Editor.
7. Реализовать и проверить недостающие игровые системы до объявления релиза.

## Известные ограничения

- Офлайн-тесты проверяют Python-логику и отдельные признаки исходного C++, **не компилируют** C++.
- Надёжное восстановление прав владельца на публичном сервере требует аутентифицированного сетевого идентификатора.
- Сохранения содержат данные мира и идентификаторы владельцев; папка `Saved/` исключена из Git.
- Проект доступен в GitHub публично. Наличие публичного исходного кода **не равнозначно** разрешению на его свободное использование: файл `LICENSE` пока не выбран владельцем.
- Старые QA-файлы в корне оставлены для сохранения уже опубликованных ссылок; они являются историей, а не подтверждением работы текущей Alpha.

# Дорожная карта NYVERRA: Echo Frontier

**Текущий этап:** Alpha 0.61 · Unreal Engine 5.8 · Windows · C++.

Дорожная карта отражает технические приоритеты, а не обещание сроков. Номер Alpha **не равен проценту готовности игры**. Каждая система считается завершённой только после реального тестирования в Unreal Engine.

## Разработка

| Этап | Цель | Состояние |
| :--- | :--- | :--- |
| **Техническое ядро** | Передвижение, добыча, инвентарь, крафт и базовое PvE | Прототип |
| **Выживание** | Показатели персонажа, еда и вода | Прототип |
| **Постройки и рейды** | Стены, фундаменты, двери, ремонт, урон по базам | Прототип |
| **Сохранение мира** | A/B-снимки построек и восстановление после перезапуска | Исходники Alpha 0.61, тестирование впереди |
| **Стабильная сетевая игра** | Два игрока, dedicated server, права и защита RPC | Нужна полноценная проверка |
| **Игровой мир** | Сохранённая карта, биомы, точки интереса, навигация AI | Не завершено |
| **Графика и звук** | Импорт материалов, модели, анимации, освещение, эффекты | Не завершено |
| **Прогресс игроков** | Инвентарь, характеристики, аккаунты, безопасная авторизация | Не завершено |
| **Команды и развитые рейды** | Групповой доступ, баланс, рейды и сезонные вайпы | В планах |
| **Выпуск** | Windows-сборка, тесты, оптимизация, документация и безопасность | Не готово |

## Ближайшие контрольные точки

- [ ] Подтвердить компиляцию текущей версии в Unreal Engine **5.8**.
- [ ] Загрузить в GitHub проверенную `TestWorld.umap` и все зависимости.
- [ ] Испытать сохранения A/B после рестарта Standalone или выделенного сервера.
- [ ] Протестировать базовые механики с двумя игроками.
- [ ] Импортировать и проверить игровые PBR-материалы и 3D-модели.
- [ ] Утвердить модель сетевой авторизации, прежде чем разрешать публичные серверы.
- [ ] Подготовить автоматизированную проверку настоящей сборки C++ на Windows.
- [ ] После выполнения предыдущих этапов — отдельный этап оптимизации и релизной сборки.

Пункты намеренно **не отмечены выполненными без подтверждённых результатов тестирования**.

## Дальнейшие этапы

**Следующие Alpha:** устойчивость серверной архитектуры, постоянный прогресс игроков, исправление сетевых ошибок и завершение игрового мира.

**Beta:** интеграционное тестирование всех механик, корректность сохранений, PvP/PvE-баланс, оптимизация производительности, обновлённая графика и звук.

**Release:** финальная Windows-сборка и серверная конфигурация только после выполнения критериев приёмки.

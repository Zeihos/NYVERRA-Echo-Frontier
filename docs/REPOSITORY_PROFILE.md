# Настройки публичной страницы GitHub

Оформление README, SVG-обложки и документации находится в репозитории. **Описание и Topics на главной странице GitHub** редактируются отдельно через настройки владельца репозитория; изменения ниже подготовлены как готовый вариант для этих полей.

## Website

Если официального сайта проекта пока нет, **оставьте поле Website пустым**. Не указывайте вымышленные ссылки.

## Как применить

Откройте страницу репозитория → рядом с блоком **About** нажмите значок редактирования (шестерёнка) → вставьте Description и Topics → сохраните изменения.

## Приоритет перед публичным релизом

- Утвердить лицензию, когда будет ясно, какие зависимости и ассеты можно распространять.
- Не заявлять о наличии готового скачиваемого билда, если он не собран и не протестирован.
- Добавлять скриншоты только из настоящего игрового процесса; текущая SVG-обложка — отдельная концептуальная графика.

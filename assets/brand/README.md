# Фирменные материалы NYVERRA

В каталоге находятся **исходные векторные изображения для оформления GitHub**:

- [Обложка проекта](nyverra-cover.svg) — широкоформатный заголовок README.
- [Монограмма N](nyverra-mark.svg) — компактный знак для будущих карточек и оформления.

Стиль: тёмный графит и сине-зелёные акценты, горный горизонт, геометрическая монограмма. Файлы выполнены в SVG, остаются чёткими при масштабировании и не зависят от внешних изображений.

**Это графическое оформление репозитория, а не игровые ассеты или настоящие скриншоты Unreal Engine.** Векторные материалы не объявляются лицензированными для стороннего использования: общие условия проекта пока не опубликованы.

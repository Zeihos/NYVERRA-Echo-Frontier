# NYVERRA: Echo Frontier — Alpha 0.63

**Этап:** прототип игровых механик и безопасности сетевого инвентаря. **Дата:** 18 ноября 2026 года. Изменения внесены в `main`; реальная компиляция C++ в Unreal Engine 5.8 здесь не проводилась.

## Что изменено

| Система | Изменение |
| --- | --- |
| Медицина | Новый предмет **Bandage / бинт** с ID 7 |
| Крафт | **6** — 2 ягоды + 1 вода → 1 бинт |
| Лечение | **H** — расходует бинт и восстанавливает до **35 HP** |
| Ограничение | Сервер принимает лечение не чаще одного раза за 4 секунды |
| Безопасность | Нельзя лечиться мёртвым, без бинта или при полном здоровье |
| Инвентарь | Репликация массива предметов и счётчиков ресурсов **только владельцу персонажа** |
| Смерть | Сервер **сразу пытается** сохранить состояние смерти с пустым инвентарём, не ждёт 20-секундного отложенного сохранения |
| Совместимость | Числовые ID прежних предметов 0–6 не изменены; бинт добавлен в конец enum |
| Сохранения | В существующем Alpha 0.62 SaveGame v1 добавлена допустимость ID 7 без изменения формата |
| Интерфейс | Количество бинтов и действия 6/H показаны в HUD и окне инвентаря |

Бинты — временная игровая механика без готовой 3D-модели, анимации и звука. Новые графические ассеты не добавлены.

## Проверка на Windows

Обновите локальный проект, затем запустите:

```bat
git pull origin main
CHECK_PROJECT_WINDOWS.bat
```

Или прямой запуск версии: `TEST_ALPHA_063_WINDOWS.bat`. При нестандартном расположении движка передайте путь, например `CHECK_PROJECT_WINDOWS.bat "D:\Epic Games\UE_5.8"`.

Этот скрипт проверяет Python-тесты и **пытается** собрать `NYVERRAEditor`; это не подтверждение функциональности в игровом клиенте.

## Ручные тесты после успешной сборки

1. Откройте проверенную карту в Unreal Engine 5.8. Добыть ягоды и воду клавишей **E**, проверить количество ресурсов.
2. Нажать **6**. Должны списаться **2 ягоды и 1 вода**, появиться один бинт. При нехватке ингредиентов крафт должен быть отклонён без потерь.
3. Проверить крафт при полном инвентаре: если материалы освобождают место или есть неполная стопка бинтов — бинт создаётся; иначе материалы не тратятся.
4. При полном здоровье нажать **H**: бинт не должен расходоваться. При 75 HP нажать **H**: здоровье 100 HP, списан один бинт.
5. При 30 HP применить бинт: здоровье становится **65 HP**. Повторное нажатие раньше чем через 4 секунды не должно тратить бинт или лечить.
6. Во время смерти и после нажатия кнопок в открытом инвентаре убедиться, что лечение и создание бинтов не выполняются.
7. Запустить двух игроков: инвентарь и счётчики ресурсов A не должны реплицироваться персонажу B; при этом B продолжает получать нужные публичные сетевые параметры движения, смерти и здоровья.
8. На **Standalone** сохранить бинты и другое содержимое, закрыть и снова открыть ту же карту. Предметы, здоровье и старые предметы с ID 0–6 должны восстановиться.
9. В тестовом окружении с резервными копиями погибнуть с бинтами и отключиться до окончания 8-секундного таймера возрождения: после нового входа старый инвентарь не должен появиться. Если запись на диск завершилась ошибкой — сервер должен отразить это в журнале.
10. Сохранить жизнь, подождать сохранения, закрыть сервер, восстановить A/B-снимки персонажа. Проверить отсутствие дублирования бинтов.
11. Запустить сетевой сервер **без** аутентифицированного OnlineSubsystem и флага `-NyAllowAuthenticatedPlayerSaves`: прогресс аккаунтов не должен сохраняться по небезопасным идентификаторам.
12. После этого отдельно проверить `NYVERRAServer` и Windows-сборку; успешные офлайн-тесты и даже компиляция Editor не доказывают корректность выделенного сервера.

## Ограничения

- Синхронное сохранение в момент смерти **снижает риск** отката, но не гарантирует сохранение при повреждении диска, отключении питания или ошибке `SaveGameToSlot`. Для реального публичного PvP потребуется транзакционный backend и подтверждение сохранения до выдачи новых предметов.
- Новый предмет пока не имеет собственной 3D-модели и визуальной анимации лечения.
- `COND_OwnerOnly` проверяется на уровне исходников, а корректность репликации и приватности нужно подтвердить в игре с двумя клиентами.
- Реальный UE5.8 C++ билд и тест с двумя игроками **пока не подтверждены**; для него нужна локальная установленная среда.
